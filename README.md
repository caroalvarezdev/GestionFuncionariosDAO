# Sistema de Gestión de Funcionarios

## Descripción
Aplicación desarrollada en Java que permite gestionar funcionarios utilizando el patrón DAO y conexión a base de datos MySQL.

## Funcionalidades
- Listar funcionarios
- Crear funcionarios
- Buscar funcionarios
- Consultar datos desde base de datos

## Tecnologías
- Java
- MySQL
- JDBC

## Base de Datos
El sistema cuenta con las tablas:
- funcionario
- cargo
- dependencia

## Patrón DAO
Se utilizó para separar la lógica de acceso a datos de la lógica del sistema.
